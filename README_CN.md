# DSC5002 小组项目：城市空气质量特征与 AQI 预测

[English](README.md) | **简体中文**

本仓库用于 DSC5002 小组项目：基于 **2025 年中国大陆 31 个省会级城市**的数据，分析城市空气质量特征，并进行 AQI 预测。

## 1. 项目概述

项目分为两个阶段。

**第一阶段：PCA 与城市聚类**

- 整理 31 个城市的年度数据。
- 使用六项污染物指标和五项气象指标，共 11 个特征。
- 采用主成分分析（PCA）降维。
- 根据主成分得分使用 K-Means 对城市聚类。
- 解释各类别的空气质量与气象特征，并可视化原始变量在 PCA 空间中的分布。

**第二阶段：AQI 预测**

- 整理 2025 年每日 AQI 与气象数据。
- 以温度、湿度、降水量、风速和气压作为预测特征。
- 对比使用同类城市合并日度数据训练的模型，与使用该类某个代表城市的数据训练的模型，在预测效果上的差异。

由于 AQI 是依据污染物浓度计算得到的，第二阶段不将同日六种污染物浓度作为预测变量。

## 3. 年度数据预处理

脚本 `src/01_preprocessing.py` 用于将各城市 2025 年月度 Excel 整理成城市级年度数据集。

### 输入文件

将 31 份月度 Excel 放入：

`data/raw_monthly/`

文件名示例：`aqistudy-北京-月数据-2025.xlsx`

各文件应与北京样例采用相同的字段结构，包含名为 `月数据` 的工作表。

### 在 VS Code 中运行

用 VS Code 打开整个 `DSC5002_Project` 文件夹，然后在项目根目录打开终端。

安装依赖：

```powershell
py -m pip install pandas numpy openpyxl
```

运行预处理脚本：

```powershell
py src/01_preprocessing.py
```

### 年度指标计算方法

| 变量 | 年度聚合方法 |
| --- | --- |
| PM2.5、PM10、SO2、NO2、CO、O3_8h | 依据每月有效日数计算加权年均值 |
| 温度、湿度、风速、气压 | 暂依据每月有效日数计算加权年均值 |
| 降水量 | 12 个月降水总量求和 |

脚本会检查字段缺失、非法数值、月份重复、月份不全等数据质量问题；**不会自动填补缺失值**。气象变量使用有效日数加权的前提是其观测覆盖日期与该字段一致，正式分析前须根据原始数据说明核对。

## 4. 输出文件

输出保存在 `data/processed/`：

| 文件 | 用途 |
| --- | --- |
| `annual_11features_raw.csv` | 交给 PCA 和聚类组员的年度原始特征表 |
| `annual_with_QC.csv` | 包含年度特征及有效日数等质量检查信息 |
| `monthly_clean.csv` | 清洗后的月度数据 |
| `data_quality_issues.csv` | 不合格文件、缺失字段和其他质量问题的记录 |

若 31 个城市均通过检查，主数据表应为 **31 行 × 12 列**：1 列城市名称加 11 列年度特征。

**注意：该表保留原始数值，尚未进行标准化、PCA 或 K-Means。** 这些步骤由负责聚类的组员另行处理。

## 5. 组员协作与文件交接

**PCA 与聚类负责人**

使用 `data/processed/annual_11features_raw.csv`。完成分析后，请分享至少包含以下字段的 CSV：

- `city`
- `PC1`
- `PC2`
- `cluster`

**可视化负责人**

依据 `city` 将聚类结果与原始年度特征表合并。在相同的 PCA 坐标系中，分别根据 11 个原始变量的数值为城市散点着色，以观察变量分布与聚类特征。

**预测模型负责人**

日度数据将单独清洗和建模。当前的月度 Excel **不能直接作为日度 AQI 预测数据**。

# DSC5002 小组项目——年度空气质量数据预处理

[English](README.md) | 简体中文

## 1. 项目介绍

本仓库主要用于 DSC5002 小组项目中的**年度数据预处理工作**。

本阶段的目标是将中国大陆 31 个省会级城市的 2025 年月度数据整合为统一的城市年度数据集，为后续主成分分析（PCA）、K-Means 聚类及聚类结果可视化提供数据基础。

最终数据包含两个维度，共 11 个特征：

| 数据维度 | 特征 |
|---|---|
| 污染物（6 个） | PM2.5、PM10、SO2、NO2、CO、O3_8h |
| 气象变量（5 个） | 温度、相对湿度、降水量、风速、气压 |

## 3. 数据来源

原始数据下载自中国空气质量在线监测分析平台（AQI Study）。

网站：https://www.aqistudy.cn/

每个 Excel 文件对应一个城市在 2025 年的月度观测数据。

示例文件名：

`aqistudy-北京-月数据-2025.xlsx`

为确保处理过程可以复现，建议保留原始 Excel，不对原始文件进行手动修改。

## 4. 数据预处理方法

运行 `src/01_preprocessing.py` 后，程序将批量读取各城市的月度 Excel，并计算相应的年度指标。

### 4.1 数据清洗与质量检查

主要预处理操作包括：

1. 批量读取 Excel，提取所需的 11 个特征。
2. 检查必需字段是否存在。
3. 将相关变量转换为数值类型。
4. 检查缺失值和非法数值。
5. 检查是否存在重复月份或缺失月份。
6. 检查每个城市是否具有完整的 12 个月记录。
7. 将发现的数据质量问题单独输出。

对于未通过完整性检查的数据，程序不会直接进行自动填补，也不会将其悄悄纳入最终年度数据集。

### 4.2 年度数据计算方法

由于变量的统计含义不同，采用不同的年度汇总方式：

| 变量 | 年度计算方式 |
|---|---|
| 六种污染物 | 按每月有效日数计算加权平均值 |
| 温度、湿度、风速、气压 | 按每月有效日数计算加权平均值 |
| 降水量 | 12 个月降水量累计求和 |

加权年度平均值的计算公式：

\[
\bar{x}_{annual}=\frac{\sum_{m=1}^{12}x_m n_m}{\sum_{m=1}^{12}n_m}
\]

其中：

- \(x_m\)：第 \(m\) 个月的观测值。
- \(n_m\)：第 \(m\) 个月的有效日数。

年度降水量的计算方式：

\[
P_{annual}=\sum_{m=1}^{12}P_m
\]

需要说明的是：目前暂时使用原始文件中的有效日数作为加权依据，气象变量的统计覆盖范围是否与其一致，还应结合数据平台的字段说明进一步确认。

### 4.3 是否进行了标准化？

**本阶段不进行标准化。**

输出文件保留各项特征原始的数值及单位。

StandardScaler、PCA 和 K-Means 均由后续负责聚类分析的组员完成，避免重复处理或错误地进行二次标准化。

## 5. 预处理结果

### 5.1 北京样例结果

目前已使用北京 2025 年月度 Excel 对预处理脚本进行了运行测试。

计算得到的年度特征如下：

| 变量 | 年度数值 | 单位 |
|---|---:|---|
| PM2.5 | 27.537 | μg/m³ |
| PM10 | 51.205 | μg/m³ |
| SO2 | 3.710 | μg/m³ |
| NO2 | 22.189 | μg/m³ |
| CO | 0.520 | mg/m³ |
| O3_8h | 94.619 | μg/m³ |
| 温度 | 14.302 | °C |
| 湿度 | 52.544 | % |
| 降水量 | 377.7 | mm |
| 风速 | 2.643 | m/s |
| 气压 | 1012.310 | hPa |

以上数据由北京月度记录计算得到，不代表经过独立核验的官方年度统计值。

北京样例已通过初步运行测试；31 个城市的完整处理情况应以实际运行结果和质量检查报告为准。

### 5.2 最终年度数据结构

在全部 31 个城市均通过检查的情况下，最终数据集应满足：

- 31 行：每行对应一个城市。
- 12 列：城市名称 + 11 个年度特征。
- 每个城市仅保留一条 2025 年度记录。
- 保留未经标准化、未经 PCA 转换的原始数值。

## 6. 输出文件说明

预处理结果统一保存在：

`data/processed/`

| 文件名 | 作用 |
|---|---|
| `annual_11features_raw.csv` | 最终年度特征数据，提供给 PCA 和聚类负责人 |
| `annual_with_QC.csv` | 包含有效日数等辅助检查信息的年度数据 |
| `monthly_clean.csv` | 清洗后的各城市月度数据 |
| `data_quality_issues.csv` | 缺失字段、月份不全、无效数据等质量问题记录 |

其中，**`annual_11features_raw.csv` 是本阶段最主要的交付成果。**

## 7. 如何运行代码

使用 VS Code 打开整个 `DSC5002_Project` 项目文件夹。

打开终端，安装依赖：

```bash
py -m pip install pandas numpy openpyxl
```

在项目根目录执行：

```bash
py src/01_preprocessing.py
```

运行完成后，进入 `data/processed/` 查看生成的文件。

正式使用年度数据进行 PCA 前，请先确认全部 31 个城市均通过质量检查。
